## 1. 最高优先级：四次方程的常数项

### 1.1 问题

`p3p.py::_quartic_coefficients` 中第一条二次式写作

```
(I): (A-1)u² + (2cosα - 2A·cosγ·v)u + A·v² - 1 = 0
```

按升幂系数应为 `C1 = [-1, 0, A]`，原代码是 `[-A, 0, A]`。

### 1.2 成因（按可能性排序）

1. **抄写/整理时的符号漂移**——最可能。函数注释本身写的就是 `C1 = A v² - 1`，
   与代码不一致；说明推导是对的，落代码时把常数项写成了 `v²` 的系数乘以 `A`。
2. **归一化选择混淆**：若把整式除以 `A`，常数项会变成 `-1/A`，看起来像 `-A`。
   但同函数里 `A1`、`B1` 都没除，所以不成立。
3. **不是浮点问题**：差异是 `A-1` 量级，不是舍入。

### 1.3 为什么方形实验完全没暴露

方形标记按 `[TL,TR,BR]` 取前三点时 `a = c`，于是 `A = (a/c)² = 1`，
`-A ≡ -1`，两条式子逐位相同。**只要换成长宽不等的矩形、或任意三点，就会立刻出错。**

这也解释了为什么 1500 组蒙特卡洛、两个闭环全部"通过"：它们的几何是同一个正方形。

### 1.4 修复与证据

```diff
-    C1 = np.array([-A, 0.0, A])
+    C1 = np.array([-1.0, 0.0, A])
```

| 检查 | 修复前 | 修复后 |
|---|---|---|
| 审查反例的归一化残差 `F(v_true)` | 8.50e-01 | **5.87e-17** |
| 300 组随机非共线三角形，最大归一化残差 | — | **1.14e-11** |
| 方形构型（A=1） | 2.0e-16 | 2.0e-16（不变） |
| `test_p3p_regression.py` | — | **9/9 通过** |

回归覆盖面（`src/test_p3p_regression.py`）：方形、矩形（A=4）、不等边四点、
点序重排、尺度缩放 0.01–10×、近共线 1.1°、完全共线、三点候选完备性、
0.3 px 噪声精度底线。

### 1.5 修复要点（给以后的人）

1. **只改这一行**，不要顺手重构。评审说得很对：同时大改会掩盖新问题。
2. **先固定稳定版本**（`git commit`），再改，再跑回归。
3. **测试集必须包含非退化几何**。这次的教训不是"公式难"，而是"测试几何太单一"——
   一个所有实验都用正方形标记的项目，等价于只测了 `A=1` 这一个特例。
4. **验证要分两层**：先验系数恒等式（把真值距离比代回 `F(v)`，应为 0），
   再验端到端解算（零噪声恢复位姿）。只做前者会漏掉回代/选支错误。

> 面试价值：这是"我自己发现并修复的 bug"的完美素材——有反例、有一行修复、
> 有回归、有"为什么之前没发现"的解释。比任何自夸都可信。

## 2. 平移误差 ≠ 相机中心定位误差

### 2.1 定义

约定 `X_c = R X_w + t`（OpenCV 的 world→camera）。相机中心是世界系里满足 `R C + t = 0` 的点：

```
C = -Rᵀ t
```

- **平移参数误差**：`‖t - t_gt‖` —— 两个平移向量的差，坐标系是相机系。
- **相机中心误差**：`‖C - C_gt‖` —— 两个三维点在**世界系**里的距离。

两者一般不相等。一阶展开：

```
‖ΔC‖ ≈ ‖Δt + δθ × t‖   ⇒  旋转误差 δθ 会把 ‖Δt‖ 放大到 ~ ‖t‖·δθ
```

### 2.2 实测差多少（`src/metric_check.py`，2000 组，σ=0.3 px，0.2 m 方形）

| 指标 | 中位 | P95 |
|---|---|---|
| `‖Δt‖` | **2.31 mm** | 11.44 mm |
| `‖ΔC‖` | **10.91 mm** | 42.48 mm |
| 比值 | **4.18×** | 24.8× |

按旋转误差分层，放大倍数随转角迅速上升：

| 旋转误差 | 样本 | `‖Δt‖` | `‖ΔC‖` | 比值 |
|---|---|---|---|---|
| 0–0.5° | 591 | 1.46 mm | 3.85 mm | 2.1× |
| 0.5–1.0° | 713 | 2.15 mm | 10.03 mm | 4.2× |
| 1.0–2.0° | 526 | 3.61 mm | 22.15 mm | 6.2× |
| 2.0–5.0° | 161 | 3.72 mm | 44.62 mm | 11.3× |

### 2.3 对现有结论的影响

1. **基准表的 2.47 mm 必须叫"平移参数误差"**，不能叫"相机定位精度"。
   同数据下相机中心误差中位 ~10.9 mm——量级差 4 倍，说错就是夸大。
2. **闭环的 1.04 mm / 3.33 mm 本来就是相机中心口径**：`pbvs.pose_error` 返回的是
   `p_cur - p_des`，其中 `p = -Rᵀt`。所以闭环数字与基准数字**不能直接比较**，
   一个是任务误差，一个是估计器参数误差。
3. **横向比较仍然公平**：所有方法都用同一个 `‖Δt‖` 口径，比值结论（自研 vs EPnP）
   不受影响；受影响的是"绝对精度"的表述。
4. **下游含义**：抓取/对准关心的是末端或相机中心在世界系的位置，用 `‖ΔC‖` 更贴近任务；
   而标定/优化内部用 `‖Δt‖` 更方便。两者都要报。

### 2.4 建议的表述模板

> 位姿估计精度：平移参数误差中位 2.47 mm、旋转 0.77°（σ=0.3 px）；
> 同数据换算到相机中心误差中位 10.9 mm（`metric_check.py`）。
> 闭环稳态为相机中心误差 1.04 mm（xArm6）/ 3.33 mm（自由相机）。

## 3. 多照片筛选：奇异分层能做什么

### 3.1 问题形式化

给一组照片（或多帧、或多个三点组合），要选出对位姿恢复最有利的子集。评判标准有三层：

1. **可解性**：这一组三点是否接近退化（解合并、二义性无法消歧）；
2. **精度**：像素噪声传到 6D 位姿的放大系数；
3. **信息量**：与其他视图是否互补（基线、视角、尺度）。

### 3.2 文献的主要工作（孙雪莹，2026，深圳大学硕士论文）

《基于计算代数几何的 P3P 问题奇异性分析》做的事情，正好是第 1 层的**几何刻画**：

- **方法**：不用"消成单变量 + 判别式"的老路，而是保留方程组的多变元结构；
  用局部对偶空间、高阶微分算子构造**判别式理想**，再用**代数簇不可约分解**剔除退化分支，
  得到 P3P 奇异构型的完整几何分层。
- **主分层**（相机中心 O 的位置）：

| 重数 | 相机中心落在 |
|---|---|
| m ≥ 2 | 观测三角形定义的**危险圆柱**上 |
| m ≥ 3 | 与观测三角形**第一 Morley 三角形**相关的危险圆柱的**三条母线**上，或在**外接圆**上 |
| m ≥ 4 | 观测三角形的**外接圆**上（无穷多解） |

- **互补分层**（与奇异解配对的另一支解）：

| 重数 | 互补相机中心落在 |
|---|---|
| m ≥ 2 | 与危险圆柱相关的 **12 次三角（Deltoidal）曲面** |
| m ≥ 3 | 该曲面的**三条尖点（Cuspidal）曲线** |

### 3.3 这些结论怎么用在"照片筛选"上

**(a) 几何硬约束：把退化集当禁区**

给定三个空间点（标记角点已知），危险圆柱与外接圆是**可以离线算出来的**。
对每个候选视角，算相机中心到圆柱面的距离 `|ρ - R_circ|`（ρ 为到圆柱轴的径向距离）
与到外接圆的距离；接近 0 就降权或直接剔除。

适用条件：三点几何已知（标记场景满足）、相机中心有粗估计（上一帧或粗解）。
代价：几乎为零，可离线建"工作空间风险图"。

**(b) 代数软判据：判别式 / 根间距**

危险圆柱对应"四次方程出现重根"，所以判别式 `Δ` 或最小正实根间距是它的**数值代理**。
本仓库现在用的就是根间距（阈值 1e-3）。

- 优点：不需要知道相机位置，解完就知道；
- 局限：**只是当前三点组合的局部指标**，不是全局完备判据；根的顺序、缩放会影响数值。
  所以它在 README 里被写成"度量/预警"，而不是"判据"。评审第 5 条提醒得对。

**(c) 互补分层：它能给的是"解集结构"，不是"真伪标签"**

这一点必须先纠正一个我之前的过度表述。互补分层描述的是：**与主分支配对的另一组解，
其相机中心落在哪张曲面上**（m≥2 → 12 次三角曲面；m≥3 → 其三条尖点曲线）。
它回答的是"还会有几支解、它们可能在哪里"，**不携带"哪一支是真实相机"的信息**。

因此：

- 候选中心靠近 12 次三角曲面，**不能**据此判它是伪解。互补构型本来就可能满足同一组
  P3P 观测 —— 它是**合法的另一组解**，而非必然的错误分支。
- 真正能说的只有：靠近该曲面意味着解**成对出现、对噪声敏感**，两支的方差都会变大。
  这是**可靠性**判断，不是**正确性**判断。
- 要判真伪，只能引入观测之外的证据，且必须组合使用：
  (i) 第 4 点及以上的重投影一致性（对镜像解往往不够，两支可能都很小）；
  (ii) 全部点 z>0（在相机前方）；
  (iii) 可见性/遮挡约束；
  (iv) 时序连续性（当前实现的做法）；
  (v) 多视图三角化一致性。

**可用且站得住的用法**有三条：

1. **解集完备性体检**：候选数与理论重数是否匹配。少解 → 数值丢根（`E_v→0` 分支、
   虚部判据过严）；多解 → 观测或点对应有问题。这是**代数结构**层面的健康检查。
2. **敏感度预警的几何版本**：主分层（危险圆柱/外接圆）是可离线算的硬约束，
   与 (b) 的根间距互为交叉验证。
3. **把它写成研究假设**，而不是现有算法的优势：*"互补几何与分支歧义、数值敏感性的
   关系，以及如何用额外对应点/多视图/带不确定度的时序先验来选择候选"* ——
   这句话适合回答"下一步想研究什么"，不适合当作"本算法优于现有方法"的证据。

**(d) 信息层：多视图选优**

单视图不退化 ≠ 多视图最优。给每个候选视图构造 Fisher 信息
`Jᵀ Σ⁻¹ J`（Σ 为角点像素协方差），按 D-最优准则（最大化行列式）选子集；
硬约束是 (a)(b) 的退化过滤。这样能自然解释"为什么加一个侧视角比加三个近似同视角更有用"。

### 3.4 一个可落地的筛选流程

```
候选照片/三点组
  ├─ 1. 几何过滤: 到危险圆柱/外接圆距离 < ε → 丢弃         (O(1) 每张)
  ├─ 2. 数值校验: 解四次方程, 根间距 < 1e-3 → 降权          (已有)
  ├─ 3. 解集体检: 候选数是否与理论重数匹配 → 发现丢根/多解   (代数结构检查,
  │              注意: 不能用作"互补解即伪解"的选支判据)
  ├─ 4. 信息排序: D-最优 / 视角基线增益 → 选 top-k          (需协方差模型)
  └─ 5. 一致性: RANSAC 或时序滤波融合, 再精化
```

取舍：1、2 便宜且可解释，先做；3 只需比较候选数，几乎零成本，但**结论只到"解集是否完整"**，
到不了"哪支为真"；4 需要标定像素噪声模型，收益在多视图场景才明显。

## 4. 两个模块的优化方向

优先级定义：**P0 = 影响正确性/可信度，必须做；P1 = 影响指标，近期做；P2 = 工程化，中期做。**
难度：★（半天）★★（几天）★★★（一到两周）。

## 6. 表述纪律（写进 README/简历前自查）

1. 说"平移参数误差"就别配"相机定位精度"的图；说"相机中心误差"就注明 `C = -Rᵀt`。
2. "失败率 0.8% vs 31.4%"必须带条件：1500 组、σ=0.3 px、30 mm/5°、方形标记。
3. 不称"提出新算法"；称"独立实现 + 工程化"。
4. 不称根间距为"完备/全局连续判据"；称"退化度量/预警"。
5. 30 Hz 只能表述为"采样设定与算法预算"，吞吐另报。
6. 仿真结论不外推到真机；"提取仿真运动学参数"≠"真机已标定"。
7. 与 OpenCV 比精度是"持平"，优势写"可解释中间量 + 退化鲁棒 + 闭环集成"。
8. **不把"靠近互补曲面"当成"伪解判据"**：互补解是合法的另一组解，曲面只描述解集结构；
   能说的是"成对出现、对噪声敏感"（可靠性），不是"它是错的"（正确性）。
9. 不说"整条管线完全不调用 OpenCV"：闭式解无候选时有 `cv2.solvePnP(EPnP)` 兜底。
10. 不说"每候选都做 LM"：实际是排序后前 3 个；也不说"上一帧给 LM 做 warm-start"：
    上一帧位姿只用于候选间选支，LM 初值恒为闭式解候选。
11. 不说"返回成功即通过重投影阈值"：`reproj_thresh` 目前只占位、未执行门限。
