# IBVS → PBVS: 自研 P3P + 六轴机械臂视觉伺服

> **来源与致谢**：本仓库的单目 IBVS 仿真基线来自 Varun Edachali 的 MIT 开源项目
> `Image-Based-Visual-Servoing`（原始 LICENSE 保留，见 `LICENSE`）。
> 在此之上新增：自研 P3P 闭式求解器、PBVS 控制律、解析 FK + DLS 逆运动学、
> xArm6 eye-in-hand 闭环、蒙特卡洛基准与全部实验分析。
>
> 环境：Python 3.10（`conda env ibvs310`）；机械臂模型用 `pybullet_data` 自带的
> `xarm/xarm6_robot.urdf`，无需额外下载资产。

基于 PyBullet 的视觉伺服仿真, 三个递进阶段:

1. **IBVS** (原始基线): 图像雅可比把像素误差映射为相机速度, 深度来自 depth buffer 查表
2. **PBVS** (自由相机): 自研 P3P 闭式解 + LM 精化直接从 4 个角点恢复 6D 位姿,
   误差定义在 SE(3) 空间, 深度"免费"获得, 不再依赖深度图
3. **PBVS + xArm6** (eye-in-hand): 位姿误差经 DLS/LM 逆运动学变成六轴关节指令,
   关节位置伺服执行 —— 完整的真实机器人闭环

## 实测指标 (全部来自本仓库脚本的真实运行结果)

> **指标口径 (勿混用)**：下表"平移误差"是 **‖t − t_gt‖**, 即 X_c = R X_w + t 的平移参数;
> 闭环图与 `pose_error` 用的是 **相机中心误差** ‖C − C*‖, C = −Rᵀt。两者一般不相等:
> 同一批 2000 组数据、σ=0.3 px 下, ‖Δt‖ 中位 2.31 mm, ‖ΔC‖ 中位 10.91 mm
> (`src/metric_check.py`)。闭环的 2.51 mm / 4.04 mm 都是**相机中心**口径。
> 注意比值**不是常数**: 一阶展开 ‖ΔC‖ ≈ ‖Δt + δθ×t‖, 旋转小时可 <1
> (单帧实测 5.53 vs 4.38 mm, 0.79×), 只能说"中位 4.18×", 不能说"恒为 4 倍"。

### P3P 蒙特卡洛基准 (1500 组位姿, 0.2 m 方形标记, 失败阈值 30 mm / 5°)

姿态采样是随机旋转向量 (各分量 U(-45°,45°), 实际转角中位 44°、最大 76°), 不是三轴欧拉角。

| 方法 | 失败率 σ=0.3px | 失败率 σ=0.5px | 平移中位误差 σ=0.3px | 旋转中位 σ=0.3px | 单次耗时 |
|---|---|---|---|---|---|
| 自研 P3P (闭式, 3 点) | 8.8% | 18.5% | 3.51 mm | 1.05° | 2.5 ms |
| **自研 P3P + LM (完整管线)** | **0.7%** | **3.9%** | **2.26 mm** | **0.70°** | 7.8 ms |
| cv2 EPnP | 31.4% | 49.4% | 4.55 mm | 1.79° | 0.20 ms |
| cv2 EPnP + LM | 10.6% | 13.1% | 2.29 mm | 0.73° | 2.5 ms |
| cv2 P3P + LM | 0.7% | 3.8% | 2.26 mm | 0.70° | 2.4 ms |
| **cv2 IPPE + LM** (平面专用) | **0.7%** | **3.9%** | **2.26 mm** | **0.70°** | 2.6 ms |
| cv2 IPPE_SQUARE + LM (方形专用) | 0.7% | 3.9% | 2.26 mm | 0.70° | 2.5 ms |

结论要分开说，不能混：

1. **未精化时，IPPE 明显强于本仓库的闭式解**（2.39 vs 3.51 mm，失败率 1.7% vs 8.8%）。
   原因很直接：IPPE 用 4 点单应估计，我们只用前 3 点做闭式解。
2. **统一 LM 精化后，四个方法完全打平**（2.26 mm / 0.70° / 0.7%）。
   这说明精化器把初值差异抹平了——**闭式解的价值是给 LM 一个不漏解的初值集，
   而不是更准的终值**。
3. 相对 EPnP 的优势是真实的：失败率低一个数量级（0.7% vs 31.4%）。
4. 纯 NumPy 比 OpenCV C++ 慢：闭式解约 14×，含统一精化约 3×。
   耗时为本机实测（同一进程内计时），其它机器上会变，**比值比绝对值可靠**。
   C++ 移植的主要收益点是 `np.roots`（伴随矩阵特征分解），不是 SVD。

**近奇异专项** (最病态 20% 位形, P3P 根间距中位 0.04):

| 方法 | 失败率 | 平移中位 |
|---|---|---|
| **自研 P3P + LM** | **24.2%** | 7.31 mm |
| cv2 P3P + LM | 24.2% | 6.98 mm |
| cv2 IPPE + LM | 30.0% | 6.50 mm |
| cv2 IPPE_SQUARE + LM | 25.8% | 7.38 mm |
| EPnP | 78.3% | 5.04 mm |
| EPnP + LM | 33.3% | 5.73 mm |

近奇异场景下自研方法与 cv2 P3P 持平，没有优势也没有劣势——这一点如实记录。

| 收敛时间 (判据 <5 mm / <0.8° 连续 10 步) | **4.17 s** (第 125 步) |
| 稳态相机中心误差 (末 20 步均值) | **4.04 mm** (末 20% 窗口为 4.59 mm，见下) |
| 稳态旋转误差 | **0.36°** |

**稳定性 (B1，`src/stability.py`)** — 单看均值会掩盖振荡，所以单独列：

| 指标 | 数值 | 含义 |
|---|---|---|
| 稳态振峰峰值 p2p | **7.90 mm** | 抖动量级 **大于** 均值 (4.59 mm) |
| 逐帧抖动 RMS | 2.92 mm/step | 高频分量强度 |
| 差分符号反转率 | **0.79** | 接近"每步翻转"，典型极限环而非随机噪声 |
| 2%·e₀ 调节时间 | 未达到 | ±4.47 mm 带内从未稳定 |
| 末端速度 RMS / 加速度 RMS | 7.6 mm/s / 318 mm/s² | 指令仍在小幅来回 |

机理：P3P 的 LM 在两个相近局部极小之间逐帧跳变，一阶低通 (α=0.4) 压不住，
控制器变成"追噪声"闭环。**这不是估计器精度问题，是滤波/增益匹配问题。**

参数扫描后取 **α=0.2、λ=2.5**，并用 3 个随机初值复核（不是对单个 seed 调参）：

| 配置 | 收敛时间 | 稳态均值 | p2p | 抖动 RMS |
|---|---|---|---|---|
| α=0.4, λ=1.5（原配置） | 2.15 s (1.77–2.53，seed 3 未达) | 4.46 mm | **8.42 mm** | 3.34 mm/step |
| **α=0.2, λ=2.5** | **1.60 s** (0.93–2.47) | **1.96 mm** | **3.77 mm** | **1.60 mm/step** |
| 改善 | 略快，且 3/3 收敛 | **2.3×** | **2.2×** | **2.1×** |

取舍：α 越小相位滞后越大，所以必须同时报 `(收敛时间, p2p)` 这一对，不能只报一个；
λ 再往上（λ=2.5 配 α=0.4）会在部分初值下压不住噪声而不收敛，说明**两个参数要成对调**。

## 自研 P3P 求解器 (`src/p3p.py`)

- **闭式核**: Grunert 式消元 —— 三角约束 (余弦定理) + 结式消元 → 一元四次方程,
  每个正实根回代出距离三元组, 再由三点正交基直接恢复旋转 (无 SVD)
- **工程层**: 按 4 点重投影 RMSE 排序后, **前 3 个候选**各做 LM 精化（不是全部 4 个）；
  再按重投影可接受性 + 与上一帧位姿的接近程度**选支**
  (平面标记的二义分支重投影几乎相同, 用上一帧位姿选支 —— 真实伺服系统标准做法)
  - 措辞边界: 上一帧位姿只用于**选支**, 不作为 LM 初值（LM 初值恒为闭式解候选）
  - 措辞边界: 闭式解**一个候选都没产出**且 `use_lm=True` 时, 入口会用 `cv2.solvePnP`
    (EPnP) 给一个初值再走自研 LM 兜底。主几何核全自研, 但这个兜底路径存在,
    不能说"整条管线完全不调用 OpenCV"
- **奇异性度量**: 四次方程最小正实根间距 (danger cylinder 判据), 连续量输出。
  它只是**诊断量**, 不参与"是否精化"的切换（后者只由 `use_lm` 控制）

### 图像点与 3D 点从哪来（`trace_pose.py` 可逐项打印）

| | 来源 | 是否每帧变化 |
|---|---|---|
| 3D 点 | `scene.PTS_M`: 由印刷边长 0.30 m 推出的 4 个角点 (标记系 z=0), 经 `R_WM`/`MARKER_CENTER` 变到世界系 | **不变**, 是模型先验, 不从深度图/点云提取 |
| 图像点 | `render()` PyBullet 光栅化 → `cv2.aruco` (DICT_4X4_1000) 检测 + `CORNER_REFINE_SUBPIX` (win 5, 30 iter) | 每帧变 |
| 对应关系 | 靠 ArUco 角点序 `[TL, TR, BR, BL]` 与 `PTS_M` 定义顺序一致 | 固定 |

- **只用 4 个点**（单个标记的全部角点）。闭式解用前 3 个, 第 4 个用于候选排序、LM 残差、选支。
- **对应的唯一性可验证**: 循环偏移 0 时 mean|Δuv| = 0.61 px, 其余三种偏移 68/131/69 px。
- `detect_corners` 取 `corners[0]`, **不按 ID 过滤** —— 多标记场景会出错, 是已知边界（B3）。
- 4 点 = 8 个约束、6 个未知量 ⇒ **残差只剩 2 个自由度**, 角点误差几乎被位姿吸收:
  实测角点偏差 0.61 px、LM 后 reproj 仅 0.29 px, 但位姿误差仍有 5.5 mm。
  **低重投影 ≠ 低位姿误差。**

- 实现中踩过的坑 (面试可展开):
  - 方形标记使 a/c ≡ 1, 回代方程 (I) 时结式恒为零 → 必须回代 (II)
  - 四次方程常数项写成 `-A`（应为 `-1`）：因为方形标记 A≡1 而**恒等隐身**，
    所以 1500 组蒙特卡洛全部"通过"；换矩形 (A=4) 立即出错。
    反例归一化残差 8.50e-01 → 5.87e-17，回归见 `test_p3p_regression.py`（9/9）
  - 候选排序用"逐点范数均值"、LM 返回"均方根"，两口径混用导致
    **LM 的改进被判为没变好而丢弃**（2.40 → 2.26 mm）。已统一为 RMSE
  - `np.polynomial` 升幂系数 vs `np.roots` 降幂约定不一致 → 解出了倒数多项式
  - 归一化坐标与像素坐标残差混用 → GN 不收敛

## DLS / LM 逆运动学 (`src/ik.py`)

- 不用 PyBullet 内置 IK (残差 ~10 mm 且不可复现), 自己实现解析 FK + 几何雅可比 + 阻尼最小二乘 `Δq = Jᵀ(JJᵀ+λ²I)⁻¹e`
- **自适应阻尼**: λ 由雅可比最小奇异值 σ_min 自适应, 近奇异时按
  (σ_safe/σ_min)² 放大 —— 关节速度有界, 这就是"奇异构型检测 + LM 阻尼切换"
- FK 经三配置标定与 PyBullet 逐位姿一致 (1e-6 mm), 雅可比与 calculateJacobian 吻合

### λ 到底起没起作用（如实记录的边界）

`damping()` 返回的是 λ, 但进方程的是 **λ²**。由于 λ = λ0·(σ_safe/σ_min)²,
有效正则化实际按 **(σ_safe/σ_min)⁴** 增长。当前手眼配置 λ0 = 2e-3、σ_safe = 0.06:

| σ_min | λ | λ² | λ²/σ_min² | 效果 |
|---|---|---|---|---|
| 0.088（实测最小） | 2.0e-3 | 4.0e-6 | **5e-4** | 与无阻尼等价 |
| 0.060（标称阈值） | 2.0e-3 | 4.0e-6 | 1.1e-3 | 仍然可忽略 |
| 0.040 | 4.5e-3 | 2.0e-5 | 1.3e-2 | 仍可忽略 |
| **0.019（等效起点）** | 1.9e-2 | 3.7e-4 | **≈1** | 开始真正起作用 |
| 0.005 | 0.29 | 8.3e-2 | 3300 | 近乎冻结 |

结论（面试要能自己说出来）:

1. **标称切换点 σ_safe = 0.06，但真正影响解的 σ_min 要到 ~0.019**（差 3 倍）,
   因为 λ0 比 σ 小两个数量级, λ² 项相比 σ_min² 只有 1e-3 量级。
2. 所以本实验里 "DLS" 实际一直退化为**普通最小二乘**; 日志 `singular_steps = 0`
   与 `lam = lam0` 全程不变是自洽的, 不是 bug。
3. 一旦跌破 ~0.019, 阻尼从"几乎没有"瞬跳到"近乎冻结", **没有平滑过渡**
   —— 阈值附近容易抖振。这正是 B4 要改的地方（经典 profile:
   λ² = λ0²(1−(σ/ε)²), 且 λ0 应与 ε 同量级）。
4. `J` 的平移行是 m/rad、姿态行无量纲且再乘 `rot_weight=0.15`, 量纲本就混合,
   所以 λ 的"物理单位"是启发式的 —— 这也是 B4 要先做量纲归一化的理由。

## 已修复的关键问题

- **四次方程常数项** (2026-10-21, 第三方审查): `_quartic_coefficients` 的 C1 原为
  `[-A, 0, A]`, 按 `(A-1)u² + (2cosα - 2A cosγ·v)u + A v² - 1 = 0` 应为 `[-1, 0, A]`。
  方形标记 `A=(a/c)²=1` 时两式恒等, 所以此前的方形实验无法暴露; 换成长宽不等的标记
  或任意三点即失效 (反例归一化残差 0.85 → 修复后 5.9e-17)。已由
  `test_p3p_regression.py` 覆盖 (9/9 通过)。

## 已知边界 (诚实声明)

- 控制频率受 PyBullet 软件光栅化渲染限制 (~10 Hz @ 480×300); 算法核
  (P3P+LM+IK) 仅 ~8 ms, 真机 30 Hz 相机下绰绰有余
- 稳态旋转误差 ~0.3-0.4° 来自渲染抗锯齿引起的角点亚像素偏差, 可通过
  更高分辨率或角点模型标定继续压低
- 纯 NumPy P3P 比 OpenCV C++ 慢 ~13×, 工程化需 C++ 移植
